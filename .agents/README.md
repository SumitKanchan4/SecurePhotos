# .agents

Working notes for the coding assistant and for anyone working on SecurePhotos. User and
developer documentation is in the repository root and `docs/`.

| Where | What |
| --- | --- |
| `rules/` | Always-on rules: how work is done and approved, the portable app rules, and the checklists to run before a merge. |
| `skills/` | Task guides: screens (`modern-web-ui`), the vault (`vault-crypto`), code, tests and docs (`enterprise-standards-and-docs`). |
| `decisions.md` | The owner's standing decisions, one line each. |
| `plans/feedback-backlog.md` | Open feedback and tasks. Items are removed once merged. |
| `research/` | Background research on the old-photo models. |

Rules and skills describe what the app does today. When the code changes, change them too.
